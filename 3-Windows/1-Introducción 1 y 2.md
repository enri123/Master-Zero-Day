**Cuota de mercado.**
Windows domina el entorno corporativo, más del 70% de los ordenadores de escritorio en empresas usan Windows. En servidores, alrededor del 70% usan Linux, y Windows Server representa aproximadamente el 30%, especialmente medianas y grandes empresas.

**Active Directory está en el 95% de las empresas.** 
Esto es un dato dicho por Microsoft, pero corresponde con la realidad.

**PowerShell es el estándar de automatización.**
PowerShell es el estándar de automatización en Windows. Ha evolucionado muchísimo desde 2006, y ahora es multiplataforma

**Desde el punto de vista de ciberseguridad.**
Windows es el vector de ataque principal en entornos corporativos. La mayoría de ransomware, ataques de movimientos lateral, y técnicas de post-explotación están diseñadas para Windows.
