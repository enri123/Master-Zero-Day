Un **protocolo de red** es un **conjunto de reglas** y **normas** que **permiten** que los **dispositivos** de **una red se comuniquen entre sí**.

**HTTPS**, "**Hypertext Transfer Protocol Secure**", es la **versión segura** de **HTTP**, el protocolo que se utiliza para enviar datos entre un navegador web, y que asegura una conexión cifrada para proteger la información transmitida.
